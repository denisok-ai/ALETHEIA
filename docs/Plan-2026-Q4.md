## Цель квартала

**Эксперимент «Тысяча»:** продать 1 000 доступов к самостоятельному практикуму «Тело знает всё» (5 000 ₽, доступ 3 месяца, без кураторов, живых занятий и сертификата) без участия Татьяны. Главное не выручка, а поток людей, часть которых придёт на личную работу с мастером (лист ожидания).

- Реклама — только из выручки: после первых 10 продаж 50 % выручки идёт в продвижение. Порог: продажа дешевле 2 250 ₽, заявка дешевле 150–250 ₽; дороже — кампанию останавливаем.
- Холодной аудитории продаём не практикум, а бесплатный «Первый тест» и подписку.
- Метрика успеха: продажи по `acqRef` (метки `?ref=tg-/vk-/mx-/dz-NN`), переходы `SocialLinkEvent`, клики и показы в SEO-дайджесте.

**Состояние на 23.10:** витрина и онлайн-оплата ЮKassa (ООО «ЭХОТЕКА») работают с 13.10, сквозной тест пройден. Продаж 0. Органика ≈ 0 (Google: 67/91 URL в индексе, слабый краул молодого домена). Соцсети не публикуются: бот не админ канала.

## Правила, которые действуют всегда

- Исполнение — субагенты **Haiku**; координатор (Opus) ставит задачи, ревьюит дифф, сам проверяет результат.
- После любой работы — база знаний бота (`content/knowledge/avaterra.yaml`, faq/funnel/objection, веб-чат), `docs/Diary.md`, `CHANGELOG.md` [Unreleased].
- Деплой — только push в `main` (CI); перед push — `npx tsc --noEmit`, тесты, `npm run build`; `deploy:rsync` параллельно с CI не запускать.
- Прод: бэкап БД перед мутацией; никакого ffmpeg и тяжёлых задач (OOM 21.10); Telegram — только через `HTTPS_PROXY`.
- Тексты: «Аватэрра» кириллицей, без «не» в названиях и заголовках, без «метод» и «калибровка», без медицинских обещаний, цены — только опубликованные на сайте; даты для контента — `TZ=Europe/Moscow date`.
