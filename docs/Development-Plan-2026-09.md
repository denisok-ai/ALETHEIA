## 1. Резюме аудита

**Риски (по убыванию).**
1. **Нет автотестов вообще** — при 118k строк и живых деньгах. Баг ложного
   100% SCORM (сентябрь) — прямое следствие: ловить было нечем.
2. **Next 14.2 — критическая уязвимость DoS** (фикс только в Next 16),
   14.x снят с поддержки. Требует мажорной миграции.
3. **Сервер ужат до 4 ГБ** (экономия). Запас ~1.7 ГБ, но OOM-алерта нет —
   узнаем о проблеме от пользователей.
4. Админ-клиенты по 900–1900 строк (certificates.tsx, Media/Courses/Settings)
   — тяжело менять безопасно.
5. Холодные лиды (`info`) в боте не догоняются вообще — часть аудитории
   тихо теряется.

**Закрыто в ходе аудита:** 23 из 27 уязвимостей prod-зависимостей
(nodemailer SMTP-инъекция, node-cron, xlsx, 13 транзитивных) — `2cbc533`.

## 3. SEO-программа (отдельно)

Контекст: техбаза выжата (0 ошибок аудита), ИКС = 0, 48 страниц в поиске,
показы единичные, первые брендовые запросы появились. Внешние сигналы —
за владельцем/Татьяной (Дзен, Я.Бизнес). **Что можно кодом — ниже.**

- [x] **Глоссарий кинезиологии** — 25–40 коротких страниц-определений
  (`/glossary/<term>`) под низкочастотные запросы («лобный обхват что это»,
  «сверка баланса», «мышечный тест да нет», …) с разметкой `DefinedTerm`,
  перелинковкой на статьи и курсы, в sitemap и llms.txt. Самый дешёвый
  масштабируемый прирост охвата; НЧ-запросы — там, где молодой домен может
  показываться уже сейчас.
- [ ] **Data-driven темы статей:** в еженедельный SEO-дайджест добавить
  «запросы с показами без кликов» и «новые запросы за неделю» — из них
  берутся темы следующих статей (первый сигнал уже есть: «терра москва
  обучение кинезиологии»).
- [ ] Посадочная под региональный спрос: «Обучение кинезиологии: онлайн из
  Москвы и любого города» — честно про онлайн-формат, без фейкового адреса.
- [ ] **Bing Webmaster Tools** (индекс Bing питает поиск ChatGPT): инструкция
  владельцу + meta-верификация в layout, затем подача sitemap.
- [ ] E-E-A-T: у `Person` Татьяны добавить `sameAs` (Telegram-канал, Дзен,
  YouTube когда появятся) и `knowsAbout`; ссылка «автор» под каждой статьёй
  на /about.
- [ ] Проверка `AggregateRating` в JsonLdCourse на соответствие правилам
  Google (только реальные отзывы, видимые на странице) — иначе штраф.
- [ ] Core Web Vitals на 2 ядрах: замер LCP/INP главной и статьи, при
  просадке — приоритет изображений/шрифтов.
- [ ] Сдвиг CI-деплоя из ночного пика краулинга (23:30–00:30 МСК) или
  `Retry-After` на 503 в nginx — убирает отказы настоящим ИИ-агентам.

Не кодом (владелец): Дзен (материалы переданы), Яндекс.Бизнес (снимет
последний пункт диагностики Вебмастера), GSC-ключ для Google-автоматики.
