## Требует решения владельца (не трогал — риск для почты)

**MEDIUM — почтовые порты открыты наружу в обход ufw.** Docker публикует порты
mailcow на `0.0.0.0` и вставляет свои правила iptables ПЕРЕД фильтром ufw
(классический обход ufw Докером). ufw показывает разрешёнными только
22/80/443/25/587/993, но снаружи реально доступны также:

- **4190 (ManageSieve)** — управление фильтрами, брутфорс-поверхность. Подтверждён снаружи.
- **143 (IMAP cleartext + STARTTLS)** — подтверждён снаружи.
- **110 (POP3), 995 (POP3S), 465 (SMTPS)** — слушают `0.0.0.0`.

В логах dovecot видно, что эти порты уже щупает сканер (внешний IP 177.3.214.0,
«no auth attempts»). Легитимный почтовый трафик идёт по внутренней docker-сети
(172.22.x, вебмейл SOGo). Внешним клиентам достаточно 993/587/465.

**Готовый фикс (не применён):** правила DROP в цепочке `DOCKER-USER` для
110/143/995/4190 с сохранением 25/587/465/993 и localhost/docker-сетей; перед
применением — бэкап `iptables-save` в `/root/backups/iptables/`. Обратимо.

**Почему не применил сам:** это изменение фаервола живого почтового сервера.
Если у владельца/Татьяны почтовый клиент настроен на 143 (STARTTLS) или 110
(POP3), правило оборвёт им почту. Порты 4190/110/995 закрыть почти безопасно
(ими пользуются только сканеры), 143 — под вопросом. Нужно подтверждение
или разрешение закрыть по-минимуму (4190 + POP3).

## Проверено и ЧИСТО (позитивное подтверждение)

- **Авторизация API:** все 140 admin-маршрутов требуют `role==='admin'` через
  `requireAdminSession` (JWT-fallback тоже проверяет роль). IDOR / пропущенных
  проверок не найдено. Публичных маршрутов 9 — все обоснованы.
- **PayKeeper webhook:** timing-safe MD5-подпись, сумма и клиент сверяются ДО
  мутаций, идемпотентность, самолечение зачисления.
- **SQL:** только два безопасных `PRAGMA` через `$queryRawUnsafe`; остальное —
  Prisma. Инъекций нет. Python-бот — параметризованные запросы.
- **XSS:** все `dangerouslySetInnerHTML` идут через безопасный `jsonLdString`,
  кроме тела публикаций → `sanitize-html` (белый список тегов, схемы только
  http/https/mailto).
- **Сброс/установка пароля:** rate-limit, одноразовые nanoid-токены с TTL 48ч,
  общие тексты ошибок (без энумерации).
- **Rate-limit** на всех auth/публичных/LLM-эндпоинтах.
- **Middleware RBAC** корректен; приложение слушает только `127.0.0.1:3000`
  (внешняя проба портов 3000/5432/6379 — артефакт ACK-then-drop фаервола, не
  живой сервис); Postgres/Redis — только localhost.
- **SSH:** эффективно keys-only (`passwordauthentication no`, root
  `prohibit-password`), 4 jail fail2ban активны. Секреты `.env` — режим 600.
- **Секреты в git:** hardcoded-секретов не найдено (совпадения regex — имена
  полей, env-чтение, тестовые фикстуры seed).
- **Внешний периметр:** `/.env`, `/.git`, `/uploads/*`, admin-API, cron —
  отдают 401/403/404.
