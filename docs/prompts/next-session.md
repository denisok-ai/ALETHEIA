**Как работаем:**
- Все работы выполняют субагенты Haiku. Ты ставишь задачи, ревьюишь дифф и сам проверяешь результат (для видео — перераспознать звук и посмотреть кадры; отчётам агентов о видео не верить на слово).
- Деплой — только push в `main` (GitHub Actions). Перед push обязательно `npx tsc --noEmit`, `npx vitest run tests/unit`, `npm run build`. После деплоя — `npx tsx scripts/prod-verify.ts`.
- Прод: бэкап БД перед любой мутацией; на сервере не запускать ffmpeg и тяжёлые задачи (21.10 был OOM); Telegram с сервера — только через `HTTPS_PROXY` из `.env`.
- Репозиторий публичный. Секреты, платный контент курса, персональные данные, токен страницы согласования — только в `~/projects/AVATERRA/private/` (вне git). Значения ключей никогда не печатай.
- После любой работы: обнови базу знаний бота (`content/knowledge/avaterra.yaml`, `lib/telegram-bot/faq.ts`/`funnel.ts`/`objection.ts`, веб-чат), `docs/Diary.md`, `CHANGELOG.md` [Unreleased].
- Тексты: «Аватэрра» кириллицей; без частицы «не» в названиях и заголовках; без «метод» и «калибровка»; без медицинских обещаний; цены — только опубликованные на сайте.
