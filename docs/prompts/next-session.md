**Как работаем:**
- Перед push: `npm run check` (линтер + типы + типы скриптов + юнит-тесты), `npm run test:db`, `npm run build` — смотреть **код выхода** (`; echo EXIT=$?`), не хвост лога. Перед коммитом — `npm run format:changed` (Prettier только для изменённых файлов, весь код разом не форматируем).
- Деплой — только push в `main` (GitHub Actions: линтер → типы → тесты → сборка → выкладка). Коммит только с документацией — с `[skip ci]`. Параллельно с CI не запускать `deploy:rsync`. После выкладки: `npx tsx scripts/prod-verify.ts` («Всё в порядке»), `npx tsx scripts/seo-audit-live.ts https://avaterra.pro` (0 ошибок), `npx tsx scripts/llm-guard-check.ts`.
- Node 24 должен совпадать на сервере и в CI: версия в `.nvmrc`, CI читает её оттуда. Откат на 20 — `/root/backups/node20-rollback-20261122-1322/` (описан в `docs/Production-Server.md`).
- Веб-изменения проверять в браузере (Playwright): телефон 390×844 и 1280, консоль без ошибок.
- Прод: бэкап БД (`sqlite3 prisma/dev.db ".backup …"` + `pragma integrity_check`) перед любой мутацией; на сервере не запускать ffmpeg и тяжёлые задачи (OOM 21.10); Telegram с сервера — только через прокси (`HTTPS_PROXY`, gost :18080); даты контента — с сервера по Москве.
