# Выбор почтового стека для @avaterra.pro

## Решение проекта

**Основной рекомендуемый стек: [Mailcow](https://github.com/mailcow/mailcow-dockerized)** (Docker Compose).

Причины:

- Готовый набор **Postfix + Dovecot + Rspamd + антивирус/антиспам**, DKIM/DMARC-подсказки в UI.
- **Веб-админка** для доменов и ящиков.
- **HTTP API** для создания ящиков — используется кодом AVATERRA (`lib/mail-provisioning/mailcow.ts`).
- Активное сообщество и документация.

## Альтернатива

**[Mailu](https://github.com/Mailu/Mailu)** — легче по ресурсам, проще структура; меньше «из коробки». Подходит, если Mailcow тяжёл для текущего VPS. Для Mailu потребуется свой адаптер провижининга (в коде сейчас реализован **Mailcow** и режим **ручной** записи без API).

## Не рекомендуется для первого запуска

Ручная сборка только **Postfix + Dovecot + OpenDKIM +Rspamd** без обёртки — высокий риск ошибок (open relay, DKIM, лимиты). Имеет смысл только при наличии опыта администрирования MTA.
