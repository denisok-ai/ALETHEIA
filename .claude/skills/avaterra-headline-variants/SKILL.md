# Варианты заголовка и первой строки

Даём владельцу выбор из нескольких вариантов. Выбирает он. Скил не решает за него.

## Входные данные

- текст поста или статьи (или хотя бы тезис);
- площадка и тип поста из `content/knowledge/avaterra.yaml` (`post_types`), если известны;
- ограничения площадки: в Дзене заголовок статьи, в Telegram первая строка поста, в VK заголовок статьи или первая строка.

## Процесс

1. Найти главный тезис текста. Если тезисов два, предложить варианты для каждого.
2. Составить варианты по типам. Нужны не меньше пяти разных типов из списка:
   - **наблюдение о теле:** «Тело подаёт сигнал раньше, чем мы его замечаем»;
   - **узнаваемая ситуация:** «Усталость, которая не проходит после отпуска»;
   - **вопрос-наблюдение** (вопрос допустим в заголовке, но не в тревожной форме): «Где в теле вы чувствуете тревогу?»;
   - **утверждение о подходе:** «Мышечное тестирование начинается с сверки баланса» (здесь «сверка баланса», а не «калибровка»);
   - **FAQ-формат:** «Нужен ли партнёр для старта самостоятельного практикума»;
   - **ресурсная формулировка:** «Тело знает всё: как начать наблюдать свои реакции».
3. Проверить каждый вариант по правилам:
   - нет частицы «не» (правило Татьяны; проверка `titleProblems` в `lib/social/captions.ts`);
   - нет «метод», «FAQ», «Avaterra», «калибр…» (см. `avaterra-school-rules`);
   - нет обещаний результата и медицинских формулировок («вылечим», «навсегда», «гарантированно»);
   - нет кликбейта: «Вы не поверите», «Шок», «Секрет, о котором молчат врачи»;
   - длина: до 60 знаков для первой строки Telegram и заголовка VK, до 90 для статьи Дзена (это ориентир для читаемости, не лимит площадки).
4. Отметить, какой вариант сильнее по тону школы (бережно, без давления) и почему. Одна фраза.

## Формат выхода

```
ЗАГОЛОВКИ для <площадка>, тип <post_type>

1. [наблюдение о теле] <вариант> (<N> знаков)
2. [узнаваемая ситуация] <вариант> (<N> знаков)
...

Рекомендую: <номер>. Причина: <одна фраза>.
Проверка: без «не», без запрещённых слов, без обещаний — да / нет по каждому пункту.
```

Количество знаков считать по символам, а не по словам. Если подсчёт не сделан инструментом, писать «ориентировочно».

## Правила

- Минимум 5 вариантов, максимум 7. Варианты разных типов, не синонимы одного.
- Не придумывать цифры и результаты, которых нет в материале.
- Не писать от первого лица Татьяны без подтверждённого опыта.
- Не использовать вопросы в тревожной форме: «Вам страшно?», «Вы больны?».
- Тон: тёплый, спокойный, без восклицательных знаков в заголовках.
