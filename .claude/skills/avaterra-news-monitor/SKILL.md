# Монитор инфоповодов

Ищем материалы, на которые школа может отреагировать постом. Работаем по открытым публичным источникам с датами. Соцсетевые ленты и комментарии не читаем.

## Входные данные

- темы (по умолчанию из `theme_bank` в `content/knowledge/avaterra.yaml`: стресс и тело, эмоции, мышечное тестирование, осознанность);
- период: последние 7 дней от сегодняшней даты (по МСК);
- площадка, для которой ищем (Telegram, VK, Дзен).

## Ограничения

- Не скрейпить ленты соцсетей (Telegram, VK, Дзен, MAX). Не брать комментарии и ответы ни на одной площадке.
- Не выдавать поиск по индексу за полный обзор. Если инструмент поиска недоступен, сказать об этом и остановиться.
- Не выдумывать даты. Материал без видимой даты публикации исключать.
- Законодательные темы (реклама, ФАС, Роскомнадзор) — только по первоисточнику: сайт ведомства или текст закона. Новостные пересказы помечать как вторичные.

## Процесс

1. Сформулировать 4–6 поисковых запросов по темам, с указанием периода (например «стресс тело новости», «реклама Telegram ФАС»).
2. Выполнить поиск. Открыть каждый перспективный результат, проверить дату публикации.
3. Отбросить материалы старше 7 дней, без даты, с медицинскими обещаниями в источнике (для нас это не повод писать так же).
4. Для каждого оставшегося материала записать: дату (ДД.ММ.ГГГГ), источник, ссылку, одну строку «о чём», и угол для поста школы.
5. Проверить угол по `avaterra-school-rules`: можно ли говорить без диагноза и обещаний, нужен ли дисклеймер.
6. Если подходящих материалов меньше пяти, сказать об этом прямо. Не добивать слабыми.

## Формат выхода

```
ИНФОПОВОДЫ на <ДД.ММ.ГГГГ>, окно 7 дней, источники: <список поисков>

| Дата | Источник | Ссылка | О чём | Угол для школы | Дисклеймер |
|---|---|---|---|---|---|

Не проверено: <какие площадки и темы не смотрели>
```

## Правила

- Ссылки только на реально открытые страницы. Не придумывать адреса.
- Один инфоповод — один угол. Не склеивать несколько новостей в один пост без решения владельца.
- Угол пишем своими словами, без цитат длиннее одной фразы.
- Ничего не публикуем и не ставим в очередь из этого скила.
