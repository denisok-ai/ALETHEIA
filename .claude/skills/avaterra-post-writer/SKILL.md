# Пост для площадок школы

Пишем текст поста в голосе школы под одну площадку. Скил ничего не публикует. Результат — текст владельцу или файл для очереди.

## Входные данные

Спросить, если не даны:
- **идея или материал:** тема, заметка, фрагмент статьи, ссылка на страницу сайта;
- **площадка:** `telegram` | `max` | `vk` | `dzen`. VK и Дзен — готовый текст для ручной публикации (`scripts/social-crosspost.ts --to=vk|dzen`, mode=ready_post), в очередь не ставятся;
- **тип поста** (необязательно): `educational`, `pain`, `practice`, `author`, `faq`, `course`, `reflection` из `post_types`. Если не задан, выбрать по теме из `theme_bank`;
- **цель:** польза, прогрев, FAQ, переход на «Первый тест», продажа практикума (только если он на витрине, см. `avaterra-school-rules`).

## Процесс

1. Прочитать `content/knowledge/avaterra.yaml`: `brand.tone_of_voice`, `post_types` (структура и длина), `rubrics`, `cta_library`, `audiences`. Проверить, нет ли темы в `theme_bank`: если есть, взять её тип, рубрику и аудиторию.
2. Выбрать аудиторию (`audiences.id`) и один главный тезис. Если тезисов два, оставить один, второй отложить в отдельный пост.
3. Построить текст по структуре выбранного `post_type`. Пример для `educational`: крючок, объяснение (стресс, тело, эмоция), связь с подходом школы, вопрос читателю, мягкий CTA.
4. Подогнать длину под площадку:
   - Telegram: текст поста по `length` из `post_type`. Если пост идёт с видео, подпись не длиннее 1024 знаков, полный текст оставить в посте.
   - MAX: по `length`, лимит подписи 4000.
   - VK: короткий текст 300–600 знаков к клипу или ссылке; развёрнутый текст — в статье.
   - Дзен: статья по `length` из `post_type`, заголовок без «не», в конце ссылка на сайт как источник.
5. CTA взять из `cta_library` по `default_cta` типа поста. Для практикума ставить `course_body` только при продаже (см. правила школы). Текст ссылки в подписи Telegram и MAX фиксирован в коде («Практикум «Тело знает всё» →»); призыв в тексте поста пишем сами.
6. Ссылка: `https://avaterra.pro/...` с меткой `?ref=<код>`. Код = префикс площадки + номер материала: `tg-01`, `mx-01`, `vk-01`, `dz-01` (`lib/social/refs.ts`). В очереди ссылка задаётся полем `url` (глоссарий, статья блога, практикум), метка добавляется сама. Номер подбирает `avaterra-content-plan` по занятым меткам в БД; владелец может задать свой.
7. Хештеги: 2–3 штуки в конце (например `#мышечноетестирование #кинезиология`). В Telegram и VK не больше трёх. В Дзене без хештегов.
8. Проверить по `avaterra-school-rules`. Исправить найденное и повторить проверку.

## Формат выхода

Одним блоком:

```
ПЛОЩАДКА: <telegram|max|vk|dzen>   ТИП: <post_type>   РУБРИКА: <rubric>
ЦЕЛЬ: <одна фраза>   ССЫЛКА: <url с ?ref=>

<текст поста, готовый к вставке>

ПРОВЕРКА: <что проверено и результат>
ЗАМЕНЫ: <что исправлено и почему>
ДЛИНА: <знаков в тексте и в подписи>
```

Текст поста — в отдельном блоке кода, чтобы не потерялись переносы. Пояснения — вне блока.

## Правила

- Один тезис, простые слова, короткие абзацы. Обращение на «вы».
- Без выдуманных фактов, цен, дат, отзывов. Факты об авторе только из `author.facts` в yaml.
- Без «я» от имени Татьяны, если нет подтверждённого опыта из материала владельца. Тогда писать от лица школы.
- Не раскрывать платные протоколы и шаги курса (см. `avaterra-school-rules`).
- Без кликбейта и без заголовков с «не». Варианты заголовка и первой строки — в `avaterra-headline-variants`.
- Приоритет: конкретное требование задачи важнее минимума скила. Правила школы (`avaterra-school-rules`) важнее задачи.
- Текст нельзя отправлять в очередь без `avaterra-school-rules` и без проверки `buildCaption` (`scripts/social-enqueue.ts --dry`).

- `lib/social/refs.ts` — метки `?ref=`.
- `docs/Telegram-Content-Knowledge-Base.md` — шаблоны постов (раздел 9), CTA (раздел 11), формулировки (раздел 12). После чистки 17.10; старые формулировки сверять с yaml.
- `lib/content/glossary.ts` — страницы глоссария для поля `url`.
